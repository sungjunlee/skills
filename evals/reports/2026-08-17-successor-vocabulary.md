# Successor vocabulary supersession

Date: 2026-08-17

Planning and implement skills no longer name external products as
successors. `feature-spec` decomposition emits a tracker-neutral handoff
and stops. `brainstorming` records unit boundaries in the Design Handoff
and stops.
Durable or high-risk work still escalates with the local route label
`relay`; the skills do not name a next-owner product.

Committed cases and results that expect `dev-backlog shape`,
`shape unavailable`, or `Relay-plan-consumer-ready` stay as historical
evidence of the earlier contract. They are not rewritten. New host
observations should use the current skill text.

The `relay` handoff token is unchanged so existing implement and
single-unit feature-spec routes keep their meaning.
