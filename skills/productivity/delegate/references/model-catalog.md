# Model catalog

Last checked: 2026-11-22 for the Gemini rows; 2026-11-18 for the rest. Treat as stale after 30 days.

Use only when the user asks for a recommendation or gives a fuzzy model name. Prefer live provider model lists when available. These are bare family slugs, not routes: resolve the route first from the home-route table in `cli-invocations.md`, then adapt the slug to that route's id shape.

## Frontier families

| Model | Selection hint | Effort profile | Cost shape |
|---|---|---|---|
| `gpt-6.2-astra` | Hardest projects across code, computer use, and documents. May end a turn early to propose a next step, so tell it to finish the task. | `medium`; higher for complex or long-running tasks; `xhigh` scored within a point of `max` on an independent index at under half the output tokens. Always pass the effort; Codex defaults to `low` | frontier; $8/$40 per 1M in/out, $0.40 cached input; requests over 272K input bill 2× input/cache and 1.5× output on the full request |
| `gpt-6.2-sol` | Everyday coding and agents. May end a turn early to propose a next step, so tell it to finish the task. | `high` for most work; `medium` to save on scoped, checkable work; `xhigh` for the hardest. Always pass the effort; Codex defaults to `low` | flagship; $2/$10 per 1M in/out, $0.10 cached input; requests over 272K input bill 2× input/cache and 1.5× output on the full request |
| `gpt-6.1-terra` | Computer use, visual reasoning, and writing. | `medium` (API default). Always pass the effort; Codex defaults to `low` | mid; $1/$5 per 1M in/out, $0.05 cached input; requests over 272K input bill 2× input/cache and 1.5× output on the full request |
| `gpt-6-luna` | High-volume, clear-goal work, including bounded coding. | `max`; `medium` (vendor default) for simple extraction and summaries | deep value; $0.10/$0.50 per 1M in/out, $0.01 cached input; requests over 272K input bill 2× input/cache and 1.5× output on the full request |
| `claude-fable-5-2` | Demanding reasoning and long-horizon agentic work; escalate here when Opus 5.5 at higher effort misses the task's evals. | `high`; `medium`, or `low` for well-specified work, where task evals hold, telling it to finish the whole task, since both end long tasks early more often; `xhigh` for the hardest long-running coding and agentic work, only where evals show a gain; `max` only to measure the ceiling or where time and tokens don't matter. Always pass the effort; Claude Code defaults to `medium` | frontier; $8/$40 per 1M in/out, $0.20 cache read |
| `claude-opus-5-5` | Long-running agentic coding, code review, and knowledge work. | `medium` (default); `low` for scoped coding; `xhigh`–`max` only where evals show a gain, since it thinks more per turn there | premium; $4/$20 per 1M in/out, $0.20 cache read |
| `claude-sonnet-5-5` | Well-defined everyday coding, debugging, and document work, near Opus 5.5 on agentic evals; weaker on factual recall, so have it check specifics. | `high`; `medium` for well-specified coding, stating the completion condition since it may stop to check in; `xhigh`–`max` only where evals show a gain, at the highest token use measured | balanced; $2/$10 per 1M in/out, $0.10 cache read |
| `claude-haiku-5-5` | Coding-subagent work and high-volume extraction, classification, and summaries; above GPT-6 Luna on agentic evals, below Sonnet 5.5 on complex agentic coding. At `low`–`medium` it may report a change done without running a check, so name the check. | `medium` (default), including coding; `high` for longer agent runs; not `low` in long agent prompts, where it stops early; `xhigh`–`max` only where evals show a gain, at very high token use | deep value; $0.10/$0.50 per 1M in/out, $0.01 cache read; a prompt over 100K tokens pays 5× on all three |
| `grok-4.7` | Long-running agent loops, tool-heavy coding, 500K-context knowledge and document work, or an independent frontier-family review; pick it for persistence and breadth, not terminal-heavy accuracy. | `high` (vendor default); `xhigh` for long agent trajectories, at a steep output-token cost; `medium`/`low` when latency matters | value frontier; $2/$6 per 1M in/out below 200K prompt tokens, doubling above; `grok-4.7-build-fast` 2× price for 2× speed |
| `gemini-4-neon` | Complex software engineering, knowledge work, and science, between Hydrogen and Carbon. API context 1M; Antigravity up to 512K. Default for a new Antigravity conversation when none is selected. | `medium` on `agy/*` (Antigravity selector default); API default `high`; `xhigh` only where task evals show a gain over `high` | $3/$15 per 1M in/out, $0.15 cached input (implicit caching only); flat across the API 1M window; batch half price |
| `gemini-4-argon` | Efficient Gemini 4 frontier model for complex coding, agentic, math, and science work; API 1M context. | `medium` (API default); `high` only where task evals show a gain; no `xhigh` | frontier; $2/$10 per 1M in/out, $0.10 cached input (implicit caching only) through 2026-11-30, then $4/$20 and $0.20; no long-context premium; batch half price |
| `gemini-4-hydrogen` | Everyday coding and agentic workflows; API 1M context. | `medium` on `agy/*`; API default `high`; `xhigh` only where task evals show a gain over `high` | $1.50/$7.50 per 1M in/out, $0.075 cached input (implicit caching only); flat across the API 1M window; batch half price |
| `muse-wonder-1.0` | Long-running coding agents and computer use; 1M context. Below Opus 5.5 on an independent index at the same per-token price, using about half the output tokens. | no vendor guidance (Cursor lists `minimal`–`max`) | premium; $4/$20 per 1M in/out, $0.20 cached input, no long-context premium; Meta's API does not train on it, but Muse Code subscriptions default to Contributor mode, which does |
| `kimi-k3` | Long-horizon coding, tool-heavy knowledge work, or multimodal implementation where completion quality matters more than latency. | route default; API ships `max` thinking, `low` and `high` announced | frontier; high output-token and latency risk |
| `qwen3.8-max` | Complex reasoning and coding through Alibaba's Token Plan. Off-peak Credits are 50% off daily 22:00–08:00 UTC+8, so defer batchable work to that window. | route default; API has a thinking toggle, no graded effort | subscription |

Gemini 4 Carbon (`gemini-4-carbon`) is on the Gemini API. Google describes it as its most capable reasoning model: 1M context, thinking `low`/`medium`/`high` (default `medium`), and the same standard price schedule as Argon. Antigravity documents it for Google AI Ultra and Enterprise, not Google AI Pro. It was absent from this account's `agy models` on 2026-11-22, so there is no `agy/*` id here; confirm `agy models` before dispatch and do not invent one.
