# gosu-review synthesis checklist

Use this only as a final sanity check.

- Panel first.
- Panel entries include sharp takes, first fixes, and missed-by-others concerns.
- Default reviews include one challenger.
- Scores are optional and need short reasons.
- Tensions stay visible before consensus.
- Consensus only clusters findings from returned subagents, with source personas visible.
- Raw Notes include one `<details>` block per returned subagent.
- If subagents are unavailable, say so instead of simulating personas.
